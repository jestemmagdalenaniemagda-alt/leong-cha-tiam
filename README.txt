LEONG CHA TIAM WEBSITE
======================

This is a lightweight single-page website made with plain HTML, CSS and JavaScript.
No framework or build step is required.

FILES
-----
index.html      - the website content and SEO / Restaurant structured data
styles.css      - all visual styling
script.js       - menu image lightbox only
robots.txt      - allows search engine crawling
assets/logo.png - actual Leong Cha Tiam logo from the supplied branding
assets/menu.png - rendered image of the supplied menu PDF
assets/menu.pdf - original supplied menu PDF
assets/favicon.png - favicon derived from the supplied logo

HOW TO PREVIEW
--------------
Double-click index.html, or serve this folder with any simple local web server.

BEFORE PUBLISHING
-----------------
1. Confirm phone number, address and opening hours are still correct.
2. If you want a different final menu artwork, replace assets/menu.png and assets/menu.pdf using the SAME filenames. No code changes are needed.
3. After buying/connecting the final domain, add a canonical URL in the <head> of index.html and use the same domain in the structured-data "url" property if desired.
4. Upload the whole folder to GitHub Pages, Cloudflare Pages, Netlify or another static host.
